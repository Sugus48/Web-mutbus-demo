สิทธิ์ตามตำแหน่ง

เข้าถึง = แสดงเมนู/ดูหน้านั้นได้ · เพิ่ม / แก้ไข / ลบ = แสดงปุ่มในหน้านั้น
ระบบสิทธิ์ทำงานอย่างไร
  1. ผู้ใช้ทั่วไป / นักศึกษา — ทุกบัญชีที่สมัครเองจากหน้า "สมัครสมาชิก" ได้บทบาทนี้อัตโนมัติ (แผนก นักศึกษา, ไม่มีตำแหน่ง) ใช้ได้เฉพาะการใช้งานทั่วไปของเว็บ: ค้นหารอบรถ จองที่นั่ง ดูการจองของตัวเอง/QR Code และแก้โปรไฟล์ — เข้าหลังบ้านและงานคนขับไม่ได้
  2. พนักงาน — ผู้ดูแลเปลี่ยนบัญชีเป็นพนักงานได้ที่หน้า ผู้ใช้งาน / พนักงาน (ติ๊ก "เป็นพนักงาน" แล้วเลือกตำแหน่ง) จากนั้นได้สิทธิ์หน้าจอตามตารางของตำแหน่งนั้น เพิ่มจากการใช้งานทั่วไป
  3. คนขับ — ตำแหน่งที่มีสิทธิ์เข้าถึงหน้าจอ SC12 งานคนขับ เข้าสู่ระบบแล้วไปหน้างานคนขับ และถูกเลือกเป็นคนขับในรอบ/ตารางเวลาได้

แก้สิทธิ์แล้วมีผลทันทีกับทุกคนในตำแหน่งนั้น · ผู้ที่จัดการผู้ใช้ได้ (SC07) กำหนดตำแหน่งหรือแก้ไขบัญชีที่มีสิทธิ์มากกว่าตัวเองไม่ได้

ตำแหน่งนี้เป็น คนขับ (มีสิทธิ์งานคนขับ SC12) — เข้าสู่ระบบแล้วไปหน้างานคนขับ เห็นเฉพาะรอบที่ตัวเองได้รับมอบหมาย และถูกเลือกเป็นคนขับในรอบการเดินรถ/ตารางเวลาได้
หน้าจอเข้าถึงเพิ่มแก้ไขลบ
คืนค่าเดิม

คุณดูได้อย่างเดียว ไม่มีสิทธิ์แก้ไข

บทบาทนี้กำหนดไว้ในระบบ แก้ไขไม่ได้ — ทุกบัญชีที่สมัครเองได้บทบาทนี้อัตโนมัติ
สิ่งที่ผู้ใช้ทั่วไป / นักศึกษา ใช้งานได้
การใช้งานใช้ได้

ต้องการให้ผู้ใช้คนใดทำงานหลังบ้านหรือเป็นคนขับ → แก้ไขบัญชีนั้นที่หน้าผู้ใช้งาน ติ๊ก "เป็นพนักงาน" แล้วเลือกตำแหน่ง ดูรายชื่อผู้ใช้ทั่วไปทั้งหมด
